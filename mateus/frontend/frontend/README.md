# Frontend Gestão de Assinaturas

React + TypeScript + Vite. Fluxos reais de cadastro, login, assinaturas e pagamentos simulados.
Leia o README na raiz do repositório para executar o backend e o ambiente completo.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

Acesse http://localhost:5173. O proxy /backend aponta para http://localhost:8080.
Nenhuma configuração manual de rotas ou modo mock é necessária.
